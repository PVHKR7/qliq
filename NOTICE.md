## Modifications

Qliq is a locally built, source-derived adaptation. Changes made relative to the pinned upstream source (`v1.2.1`, commit `ce32cd5b88fc307ce193ba9ba1dac29d51a9f756`):

**Identity**

- Product name, bundle identifier (`com.pvhkr.qliq`), executable name, log subsystems, dispatch-queue labels and temporary-file prefixes changed from the upstream values.
- Application Support directory, Keychain access group namespace and the recording-flag file are now derived from Qliq's bundle identity, so the app neither reads nor writes FreeFlow's data.
- New application icon, generated by `scripts/make-icon.py`. The upstream icon and marketing assets are not included.

**Removed network behaviour**

- The setup and settings views no longer fetch GitHub star counts, stargazers or contributors, and the associated `GitHubMetadataCache` was deleted.
- The `UpdateManager` no longer contacts a release feed, downloads a DMG, or can replace the running bundle. It retains its public shape so existing views compile, and reports that updates arrive by rebuilding.

**Removed surface**

- DMG packaging and notarization targets.
- Upstream website, agent instructions and GitHub workflow directories.
- Unused `NSSpeechRecognitionUsageDescription` and `NSAccessibilityUsageDescription` Info.plist keys. No Apple Speech API is linked, and the Accessibility key is not read by TCC.

**Build**

- The Makefile pins the macOS 26.5 CLT SDK so SwiftUI macro attributes resolve without Xcode installed. See README.md.
- Default signing is ad-hoc, for local installation.
